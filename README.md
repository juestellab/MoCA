# MoCa - A Monte-Carlo light transport simulation tool for optoacoustic imaging

## Installation
`MoCA` requires `julia` and a CUDA capable GPU. `julia` can be installed from [here](https://julialang.org/downloads/)
To install `MoCA`, run
`julia -- install.jl`

## Usage
Examples on how to use `MoCA` can be found in `scripts/demo.jl`.
